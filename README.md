# Distance Calculator Using Structures in C

## Project Description

A simple C program that uses structures to store two distances and calculate their total.

## Features

- Enter two distances
- Add distances
- Convert extra inches into feet
- Display the total distance

## Technologies Used

- C
- Structures
- Arithmetic Operations

## How to Run

Compile and run the `distance_calculator.c` file using a C compiler.
